# q19・q104 学説文献確認 引き継ぎメモ(2026-09-14時点)

## 対象

- `data/questions/kenri/teitouken.ts`(q19)
- `data/questions/kenri/teitouken-2.ts`(q104。topicId: q19)

両問とも、以下の解釈論(以下「本解釈論」)の根拠水準が `secondary` のまま `verified: false` で止まっている(Issue #330 残り2項目)。

> 抵当権には追及効があるため、抵当不動産の**通常の売却**では、抵当権者は譲受人のもとにある不動産に抵当権を実行すればよく、**売却代金債権への物上代位は認められない(必要ない)**。

現在の問題データの表記は「判例・通説」から**「通説」**に修正済み(PR #333)。本メモは、この「通説」の根拠を**学説文献(基本書・コンメンタール・法律雑誌の解説記事等)**で一次ソース確認し、`source.level`/`answerLevel`を`primary`に格上げできるかを検討するための引き継ぎ。

## これまでに確定したこと(再調査不要)

1. **判例では見つからない**。最三小判平11.11.30(平成10(受)407配当異議事件)の判決原文を確認済みだが、これは**買戻特約の実行により抵当権自体が消滅する場面**での物上代位を認めたものであり、本解釈論が前提とする「抵当権が存続し追及効が働く通常売却」の場面とは事案が異なる。本解釈論を直接裏付ける判例ではない。
2. RETIOが公開する抵当権の設定・消滅・範囲・物上代位に関する最高裁判例一覧(明治〜平成30年、50件、ユーザーが全文貼付)にも、本解釈論に直接該当する判例は見当たらなかった。
3. 以上より、本解釈論は特定の最高裁判例に基づくものではなく、**学説(通説)としての性質が強い**と判断し、lesson・肢・解説の表記を「判例・通説」→「通説」に修正済み(PR #333、マージ済み)。

**→ 判例をこれ以上探しても見つからない可能性が高い。次に進むべきは学説文献の確認。**

## 環境上の制約(次のセッションでも再確認すること)

このセッションのネットワークegressプロキシは、`laws.e-gov.go.jp`を含む**ほぼ全ての外部ドメインへの`WebFetch`をブロック**する(`EGRESS_BLOCKED`エラー)。`WebSearch`は使えるが、検索結果はスニペットの要約に留まり、原文の逐語確認はできない。次のセッションでこの制約が変わっていないか、まず`WebFetch`を1回試すことを推奨。変わっていなければ、hiiragi17さんに該当ページ・PDFの本文を直接貼り付けてもらう(このセッションでずっと採ってきた方法)。

## 候補となる学説文献(WebSearchで発見・未確認)

いずれも`WebFetch`が`EGRESS_BLOCKED`で失敗しており、内容の逐語確認はできていない。優先度順:

1. **法学教室 2015年4月号(No.415)「論点講座68」**(有斐閣)
   URL: `http://www.yuhikaku.co.jp/yuhikaku_pr/hougaku/files/2013/03/P068X068.pdf`
   検索スニペットで「先取特権や抵当権は、その目的物の『売却、…』」という書き出しが確認でき、本論点(304条1項の「売却」への物上代位)をまさに扱っている可能性が高い。**最有力候補**。

2. **東京大学 UTokyo BiblioPlaza「抵当権者の追及権について」**
   URL: `https://www.u-tokyo.ac.jp/biblioplaza/ja/E_00001.html`
   タイトルが本解釈論の核心(追及権)そのもの。東大教員の著書・論文紹介ページとみられる。著者名・出典を確認する価値が高い。

3. **有斐閣Online「抵当権の物上代位(1)」「抵当権の物上代位(2)—債権譲渡との優劣」**
   URL: `https://yuhikaku.com/articles/-/14857` / `https://yuhikaku.com/articles/-/14858`
   有斐閣の法律解説オンライン記事(執筆者は法学者の可能性が高いが未確認)。

4. **松岡久和(京都大学・立命館大学)民法演習Ⅰ・第12回講義(抵当権と物上代位)補足説明**
   URL: `https://matsuokaoncivillaw.private.coocan.jp/Lecture2017/BasicSeminarI/12_Supplement.pdf`
   大学教員本人が公開している講義資料。学説の整理として参照価値あり(ただし「基本書」ではなく講義資料である点に留意)。

5. **名古屋大学OCW『担保物権法②』抵当権(1)講義ノート**
   URL: `https://ocw.nagoya-u.jp/files/2/note-6.pdf`

6. **道垣内弘人『担保物権法』(有斐閣)** — 担保物権法の定評ある基本書。オンラインで本文を確認できないため、hiiragi17さんが書籍を所持していれば該当箇所(抵当権の効力・物上代位の章)を直接確認してもらうのが早い可能性がある。

## 次のセッションで実行する手順

1. まず`WebFetch`で候補1〜5のいずれかに再アクセスを試す(環境制約が解除されている可能性を確認)。
2. ブロックされる場合は、hiiragi17さんに候補URLを提示し、該当箇所の本文をコピペしてもらうよう依頼する(このセッションで確立した方法)。優先度1位(法学教室の記事)から依頼するのが効率的。
3. 本解釈論(「追及効があるため通常売却では物上代位は認められない」)を直接支持する記述が見つかった場合:
   - 著者名・文献名・巻号・年を`source.note`に記録
   - `docs/verification/kenri-verification.md`のq19・q104セクションに逐語引用を追加(CLAUDE.mdの「原文と書くならエリプシスを使わない」ルールを厳守)
   - `source.level`/`answerLevel`を検討(学説文献はCLAUDE.mdの`SourceLevel`定義上どの水準に当たるか要確認——教科書・コンメンタールは基本的に`primary`ではなく`secondary`寄りになりうるため、`types/index.ts`の`SourceLevel`定義を再読すること)
   - **AIの下書き照合だけでは`verified: true`にしない**。hiiragi17さんの最終確認・承認を経ること
4. 見つからなかった場合、または学説文献確認によっても`primary`级の水準に届かない場合:
   - `secondary`のまま維持することが最終結論になりうる。その場合はq19・q104の`source.note`に「学説文献による確認を試みたが一次ソース水準には届かなかった」旨を記録し、Issue #330のq19・q104項目を「これ以上の格上げは困難」として一旦クローズ検討をhiiragi17さんに提案する。
