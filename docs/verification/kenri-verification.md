## この文書の使い方

各肢の判定を、条文・判例の**原文**と突き合わせた結果です。

`凡例` — 照合表の列構成(4シート共通):

| 列 | 意味 |
|---|---|
| 肢 | 肢の要旨。**正誤は書かない** |
| 肢の正誤 | その肢が正しいか誤りか。**`○` / `×(誤り)` の2値のみ**。問題データの `choices[].correct` に対応 |
| 根拠 | その正誤を導く条文・判例 |
| 照合結果 | 原文との突合せ結果。**記号は4シート共通**(✅=原文と一致〔一次ソース、または独立した複数のミラーで文言一致を確認したもの〕/ ⚠️=一致するが留保あり〔括弧で留保の内容を書く〕/ ⏳=原文未取得・照合未了) |
| 🚩数字 | 検算が要る数字(列がある表のみ) |

`spot`(間違い探し)の表は `肢` / `肢の正誤` に代えて `ゾーン` / `違反/適法` を使う。
`calc`(計算)の表は `段` / `計算` / `検算` の3列(根拠を書く問題は `段` / `計算` / `根拠` / `検算` の4列)で、肢の表とは別様式。`検算` 欄は数字の検算そのものを担うので `🚩` を書いてよい。
**列を混ぜない。**

- `肢の正誤` は `○` / `×(誤り)` の2値だけ。「30年になる」「旧法の記述」のような限定は `根拠` に書く
- 数字の検算は `🚩数字` 列に置く(`照合結果` に `🚩` を混ぜない。calc の `検算` 欄は例外)
- 根拠の強さは問題データの `source.level` が持つ。照合シートの `照合結果` には書かない
- `照合結果` は「**文言が一致したか**」だけを表す。その根拠が一次ソースかミラーかは問題データの `source.level` が持つ
- `照合結果` に付ける括弧書きは、**突合せ自体の限定**(どの判例で見たか・改正後条文と照合したか)に限る

- **判定はAIによる下書き照合です。** 最終的な `verified: true` の判断は、この原文を見て Mami が承認してください。
- 承認できたら、そのファイルの `verified` を `true` に上げる(フラグ導入後)。
- 一次ソースの原文は各社の条文サイト/Wikibooks/公的PDF等で再取得したもの。出典は末尾。
